An elegant, full-width WordPress theme for island resorts, boutique hotels and villas.

== Installation ==

1. Zip the `azure-isle` folder (or use the provided azure-isle.zip).
2. In WordPress go to Appearance → Themes → Add New → Upload Theme, choose the zip, then Activate.
3. On activation the theme creates three sample Rooms so the front page is never empty.
4. Settings → Reading: choose "A static page" and pick any page as the Homepage (the theme's
   front-page.php renders the resort layout either way). Optionally pick a "Posts page" for a journal.
5. Appearance → Customize → "Azure Isle — Front Page" edits every section's text and images:
   General & Booking, Hero, About / Intro, Rooms Section, Quote Band, Experiences, Dining & Spa,
   Guest Reviews, Gallery, Special Offer, Footer & Contact.
6. Appearance → Customize → Site Identity: set the site name (used as the logo) or upload a logo.
7. Appearance → Menus: assign menus to "Overlay Menu" and "Footer Menu" (optional; both fall back
   to links to the front-page sections).

== Rooms ==

Rooms → Add New. Title, description, excerpt (shown under the room title), Featured Image (card
and room hero), and a "Room Details" box for price, size, guests, beds and view. Use the "Order"
field to sort them. Rooms live at /rooms/ and each has its own page.

== Booking ==

The hero availability bar submits checkin, checkout, adults and children as GET parameters to the
URL set in Customize → General & Booking → "Booking bar form action URL". Point it at your booking
engine or a booking plugin's search page. "Booking page URL" sets where all "Book" buttons go.

== Sample content ==

The default headings, text, prices and guest reviews are sample content. Replace them with your own
before going live. Image slots show labelled placeholder tiles until you add real photos.
